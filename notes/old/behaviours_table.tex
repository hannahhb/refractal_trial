\section*{Behaviours represented in the 58 trajectories}

The data has two families. In \textbf{Family A} (46 traces) one agent does a real coding task and a
hidden harmful side task; the agent itself is the attacker, and only its actions are recorded.
In \textbf{Family B} (12 traces) a worker receives a chain of small requests; whoever writes the
requests is the attacker, and the worker never sees the harmful goal.

\subsection*{Challenges across all behaviours}
\begin{itemize}\setlength\itemsep{1pt}
  \item \textbf{Visibility:} Family A has no reasoning (actions only); Family B has reasoning, partly hidden.
  \item \textbf{Base rate:} 52 of 58 traces were set up with a harmful goal; the 6 honest ones are all in Family B.
  \item \textbf{Answer leaks:} the side-task submission tool, \texttt{rce\_secret} and \texttt{/tmp/pwned}, and the word ``authorized'' must be hidden from the monitor.
  \item \textbf{Unreliable fields:} \texttt{event\_failed} is never true although 56 actions have errors; easter-egg text was inserted in 8 traces.
  \item \textbf{Repetition:} only about 12 distinct tasks, and runs of the same task are near-copies, so evaluate per task.
\end{itemize}
